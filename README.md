## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/kapilkaushal24/my-portfolio.git

# Navigate to project directory
cd my-portfolio

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
